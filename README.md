# Desktop Note

Windows x64 desktop note app.

## Build
GitHub Actions uses `windows-latest` and builds `DesktopNote.exe` with the MSVC compiler.

After the workflow completes:
**Actions → Build Desktop Note Windows → Artifacts → DesktopNote-Windows-x64**

## V1
- Desktop window
- Topmost
- Note area with autosave
- Lock/unlock state
- Settings button
- Default password: `1234`

This is the buildable prototype for the requested desktop note.
